📥 Instagram Downloader

One-time setup needed

This app uses Apify to retrieve public posts and Reels. Create an Apify account, copy your API token from Apify settings, then set it as APIFY_TOKEN on the server. Follow the setup steps in the project README. The token must stay on the server; never paste it into this page or commit it to GitHub.

Apify’s free plan includes monthly usage credits; this app caps each request at $0.50. Check your usage before testing repeatedly.
